Mentions & hashtags

Smart tags are how Nomima understands who and what your notes are about. Tag once while writing — every view, lens and graph updates automatically.

What smart tags are

A smart tag is a small colored pill embedded in your text. There are two families:

  • @mention — who: people, teams, companies, places, products.
  • #hashtag — what: projects, ideas, topics, statuses.

Every tag becomes an entity in your Knowledge Graph. Tag @Sara in five different notes and Nomima knows they’re all about the same person — her Smart View lens, graph node and entity card collect everything in one place.

Creating a tag

Trigger menu

  1. Type @ for a mention or # for a hashtag. A suggestion menu opens immediately.
  2. Keep typing to filter — @sa narrows to names starting with “Sa”. The list is fuzzy so a few letters usually find what you want.
  3. ↑/↓ navigate the list. Enter or Tab accept the highlighted entry — Tab is quicker when you’ve only typed a couple of letters and trust the top suggestion.
  4. If no match exists, the menu shows an Add “@name” option at the bottom — press Enter to create the entity and insert the pill in one step.
  5. Esc dismisses the menu and leaves your typed characters as plain text.

Type selector

When you’re creating a new entity, a second row appears in the menu letting you pick its type (Person, Company, Project, etc.) before committing. You can change the type later from the entity card.

Ghost suggestions (inline)

While writing ordinary prose, Nomima watches for names it recognises. When it spots one, it ghosts a faint dashed pill ahead of the cursor — type “Mo” and you might see @Moe with a small ⇥ hint alongside. Press Tab to accept it as a real pill; Esc dismisses the ghost for that word and keeps it as plain text. Toggle this behaviour in Settings → Smart Tag Types → “Suggest Smart Tags as I type”.

Custom types

You’re not limited to the built-ins. In Settings → Smart Tag Types you can:

  • Add a new type to either family — pick a label, an icon from the icon gallery, and a color.
  • Edit built-ins — change a type’s icon or color (its family is fixed).
  • Delete custom types you no longer need. Reserved types like Status can’t be removed.

Custom types get their own color in the Knowledge Graph legend and their own grouping in search — they’re first-class citizens.

Entity cards & attributes

Click any pill to open its entity card — the hub for that person, project or thing:

  • Appears in — every notebook and block that references the entity, deduplicated by notebook, and clickable to jump straight there.
  • Attributes — add arbitrary fields: an email, phone and role for a person; a URL and description for a company; anything you like. Attributes are stored with the entity, not with any single note, so they follow the entity everywhere.
  • Type schema — in Settings → Smart Tag Types you can define which attribute fields a type should carry by default, so every new Person card always offers Email, Role and Company without you having to add them manually.

Entity thumbnails & favicons

Every entity can carry a custom image that replaces the generic type icon — and the image appears on every pill instance across your entire vault, not just in the entity card. This is one of the most visually impactful things you can do to make long notes scannable at a glance.

What it looks like

  • A @Sara pill with Sara’s headshot instead of the person icon.
  • A @Acme Corp pill showing the Acme logo instead of the building icon.
  • A @France location entity showing a flag thumbnail.
  • A #Nomima project pill showing the product’s icon.

The image is small (shown as a circular thumbnail ~16px in the pill) but immediately recognisable, especially when scanning a note that references many different people or companies.

How to set one

  1. Click any pill to open its entity card.
  2. Click the icon area at the top of the card (or drag an image file onto it).
  3. Choose: upload a file from disk, paste an image URL, or — for companies and products — paste the website URL and Nomima fetches the favicon automatically.
  4. Nomima fetches and caches the image locally. All pills update instantly and work offline from that point on.

Company favicons: paste a company’s homepage URL (e.g. https://stripe.com) and Nomima pulls the favicon. It’s the fastest way to brand every @Company pill without hunting for a logo file.

Removing or changing it

Open the entity card and click the image — a remove option appears. Removing it reverts the pill back to the default type icon everywhere.

Pill behavior in the editor

  • Pills are single units: ←/→ step across a pill in one keystroke, and Backspace removes it in one keystroke.
  • Hover a pill for a tooltip showing its type.
  • Pills work everywhere text does — inside task titles, reminder labels, section summaries, callouts and table cells.
  • Pasted text gets tagged too: SmartCopy converts @names, #tags and dates in pasted content into real pills (and is smart enough to leave code comments alone). See Paste, templates & shortcuts.

Why bother tagging?

Tags are the fuel for everything downstream:

  • Smart Views — open the Person lens and see every person with their open work, progress bars, and checkable items.
  • Knowledge Graph — entities become glowing nodes connected by what you wrote.
  • Smart Scrollbar — every tag paints a colored dash on the note’s minimap so you can see at a glance what a long note contains.
  • Home — group your daily agenda by @mention or #hashtag instead of by time.
