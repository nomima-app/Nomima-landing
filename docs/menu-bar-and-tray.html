Menu bar & tray

Nomima lives in your macOS menu bar even when its window is closed. Click the icon for a live glance at the app; use the native app menu and the About window for the rest.

The menu-bar tray

Nomima puts a full-colour “N” mark in your menu bar. Left-click it to open the popup — a small card that drops down just beneath the icon and closes itself the moment you click anywhere else or switch apps, exactly like a native menu-bar panel.

The popup is organised top to bottom:

  • Header — the Nomima mark, the running version, and (when one is waiting) an Update pill. Click anywhere in the header to bring the main window forward.
  • App footprint — two live sparklines, Memory and CPU, in the style of Activity Monitor. A background sampler measures Nomima’s whole process tree once a second — the core app plus its WebView helpers and the MCP server — so the numbers reflect what Nomima actually costs your Mac, not just one process. Memory tracks the same “phys footprint” figure Activity Monitor shows; CPU is per-core percent. Each card also shows a running peak. The graph holds roughly the last 90 seconds and is seeded the instant the popup opens, so it’s never blank.
  • Status chips — a compact row showing the MCP server (its port when running, “starting”, or “off”), the current vault size, and the index state (“indexing…”, or the clock time it last finished).
  • Quick actions — New note creates a notebook (the main window owns creation, so its sidebar updates and the new title auto-focuses). Record sits beside it for meeting capture; until the Meetings feature ships it shows “Coming soon” when clicked and starts a real recording once that feature lands.
  • Overdue — up to five most-overdue reminders and tasks (earliest due first), each with a compact “how late” badge like 3h or 2d. Click one to jump straight to its notebook. The count on the right is the true total, even when the list is truncated.
  • Recent — your three most recently updated notebooks with a “how long ago” label. Click to open.

Note: the popup refreshes every time it’s revealed, so its chips and lists are current each time you open it — it just shows the last-known values for a moment if a read hiccups.

Right-click the tray icon for a small menu instead: Show Nomima, Hide Nomima, and Quit Nomima. When an update is available the icon itself gains a small up-arrow badge, so you can tell at a glance from the menu bar.

The macOS app menu

With the main window focused, Nomima installs a standard macOS menu bar at the top of the screen. Alongside the usual system Edit (undo/redo, cut/copy/paste, select all) and Window (minimize, zoom, close) submenus, two menus are Nomima’s own:

  • Nomima ▸
    • About Nomima — opens the About window (below).
    • Settings ▸ — jumps straight to an in-app Settings pane: Appearance (on the standard ⌘, shortcut), Smart Tag Types, Sound, Vault, and Summon (AI model, Capabilities & Memory).
    • Check for Updates… — surfaces the main window and runs a manual update check.
    • Help & Diagnostics — opens the diagnostics pane in Settings.
    • The system Hide / Hide Others / Show All and Quit items.
  • File ▸ — New Notebook (⌘N) and Open Home (⇧⌘H), both routed into the main window.

Tip: every Settings entry here just deep-links into the same in-app Settings you can reach from the sidebar — the menu is a shortcut, not a separate window.

The About window

Choosing Nomima ▸ About Nomima opens a small, self-contained About window — distinct from Settings → About & Updates, which is where update details and diagnostics live. The About window is a compact identity card: the Nomima mark on a white tile, the app name, the current version, and a one-line description of the app.

Two buttons sit below the description: Visit website opens nomima.io in your browser, and User Guide opens these docs. Closing the window (the red traffic light) simply hides it, so the next About Nomima re-shows the same window instantly.
